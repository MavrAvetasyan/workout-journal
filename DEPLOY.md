# Публикация сайта

Исходники сайта лежат в папке `wwwroot`.

Для публикации статической версии под `GitHub Pages`:

1. Внести изменения в файлы внутри `wwwroot`.
2. Запустить скрипт:
   `powershell -ExecutionPolicy Bypass -File .\tools\publish-static.ps1`
3. Скрипт создаст папку `docs` с готовой версией сайта.
4. Загрузить содержимое проекта в GitHub-репозиторий.
5. В настройках репозитория включить `GitHub Pages`:
   Source -> `Deploy from a branch`
   Branch -> `main`
   Folder -> `/docs`

После каждой модернизации сайта:

1. Изменить файлы в `wwwroot`.
2. Снова запустить `tools/publish-static.ps1`.
3. Обновить файлы в GitHub.

Важно:

- Сейчас данные тренировок хранятся в `localStorage` браузера.
- Это значит, что история тренировок сохраняется у пользователя на его устройстве и в его браузере.
- Обновления дизайна и кода не удаляют эти данные автоматически.
- Но если пользователь очистит данные сайта в браузере, история исчезнет.
- Для более надежного хранения позже понадобится база данных или экспорт/импорт.
