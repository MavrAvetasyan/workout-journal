Как сейчас хранятся данные

Тренировки, упражнения, замеры и черновики сохраняются локально в браузере на этом устройстве.

Что уже поддерживается

Незаполненные формы восстанавливаются после обновления страницы. Для тренировок можно выбирать упражнения из заранее созданного справочника.

Резервная копия

Можно выгрузить все данные в файл и позже восстановить их через импорт. Это защитит историю от случайной потери.

Действия с данными

Экспорт сохраняет тренировки, упражнения, замеры и черновики. Очистка удаляет все локальные данные только на этом устройстве.
